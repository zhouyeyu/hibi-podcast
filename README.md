# HIBI · 两只小熊的日语日常

日语对话与中英文陪听播客的公开发布仓库。

网站：https://zhouyeyu.github.io/hibi-podcast/

## 发布方式

GitHub Pages 从 main 分支的 docs 目录自动部署。只有完成审核、登记发行时间并通过公开 RSS 校验的节目才进入发布目录。

- 中文订阅源（节目上线后）：`zh/feed.xml`
- 英文订阅源（节目上线后）：`en/feed.xml`
- 每集包括 MP3、文字稿与章节。

## 文件边界

本仓库仅保存网页及正式发布资源。模型权重、运行环境、原始音视频、草稿与账号凭据不进入仓库。

目前为网站准备阶段，尚未公开发行单集；请勿将预计订阅地址当作已上线订阅源。

内容版权归各自权利人所有；仓库公开不代表授予内容再分发许可。
