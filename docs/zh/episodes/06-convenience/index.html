便利店挑饭团：把“要不选这个吧”说自然

日语对话＋中文讲解，围绕一个表达练习替换、跟读与回答。

站在便利店的饭团货架前，口味一排排摆着，你会怎么问朋友想选哪一种？今天跟两只小熊逛一小会儿。先不用记语法，听听蓝衫小熊最后选了什么。等一会儿，你也要替自己选一次。

おにぎり、どれにする？／鮭にしようかな。／じゃあ、私も！

听出来了吗？他选的是鲑鱼口味。围巾小熊听完，也决定选一样的。我们回到第一句。

おにぎり、どれにする？

这句话是在问，饭团，你想选哪一种？眼前有几种口味，她想知道朋友准备挑哪一个。两个人很熟，说法短，语气也轻松。面对已经摆在眼前的选项，就很适合这样问。

鮭にしようかな。

他没有特别郑重地宣布决定，而是边看边想：要不，就选鲑鱼口味吧。后半句留着一点考虑的余地，像把自己的想法轻声说给朋友听。

じゃあ、私も！

这一句是，那我也选这个！她没有把鲑鱼和选择再说一遍，因为两个人都知道正在聊什么。日常对话里，已经清楚的内容经常可以省下来。

今天值得带走的，不只是某一种饭团的名字，而是一个表达选择的办法。先听一种比较确定的说法。

これにする。

意思是，我就选这个。把选中的东西放在前面，后面接表达选择的部分，就能说清自己的决定。

鮭にしようかな。

再听原句，就没有那么斩钉截铁了。说话的人已经偏向一个选项，但还在心里掂量，所以中文用要不选这个吧，会比一句生硬的我选择这个，更接近当下的感觉。你在菜单前犹豫，在货架前想一想，都可以用上。

今天抓住两种口气：决定了，就直接说自己的选择；还在考虑，就用小熊刚才那种边想边说的口气。我们练后面这一种。

走到饮料柜前，还是同一个朋友问你选哪种。这一次你想喝茶，试着把原句里的鲑鱼口味换成茶。先给你一点时间。

お茶にしようかな。

要不就喝茶吧。后半句保留，只换掉前面的选择。再来一次，这回你更想喝咖啡。

コーヒーにしようかな。

要不就选咖啡吧。同一种表达，可以从饭团货架走到饮料柜。你不用一下学会很多新单词，先用已经认识的茶和咖啡，把一个句子真正用熟。

现在跟着小熊说。听完一句，再开口，先不用追求和原声一模一样。想象你真的和朋友站在货架前，问他想选什么。

おにぎり、どれにする？

接下来，轮到你边看边决定。语气放松，不需要像报答案。

鮭にしようかな。

最后一句，是听见朋友的选择以后，觉得不错，自己也要一样的。

じゃあ、私も！

再试一轮，只保留问和答。把自己想选的东西放到句子前面。你可以选茶，也可以选咖啡。

どれにする？

最后，把提示拿走。现在你站在饮料柜前，有茶，也有咖啡。朋友问你选哪一种，你想说：要不选茶吧。自己说一次。

お茶にしようかな。

如果你换成了咖啡，也完全可以。重点是你有没有用这个句子，表达出一个自己的选择。今天还记得视频最后那个词吗？饭团。

おにぎり。

再听一遍，看看是不是更清楚了。

おにぎり、どれにする？／鮭にしようかな。／じゃあ、私も！
