售票机前：两张车票怎么说

到了车站，面前是售票机，两只小熊准备一起出发。今天不研究复杂票种，先把买什么、买几张听清楚。听完整对话时，请留意同伴确认的数量。你可以想象机器前只有两个人，每个人都需要一张车票。

切符を二枚買おう。／うん、二枚だね。

围巾小熊提议买两张车票，蓝衫小熊又确认了一次，两张，对吧。重复数量在这里有实际作用：它让同行的人知道没有买错份数。我们先把这次共同决定听明白，再练习怎样把同样的数量说给工作人员听。

切符を二枚買おう。

第一句是，买两张车票吧。它是在和朋友商量接下来一起做什么，而不是向售票员直接提出请求。商品、数量和一起买的动作，都挤在这一小句里。听的时候先抓车票，再抓两张，不必把每个音都拆开才继续听。

うん、二枚だね。

回答是，嗯，两张。朋友是在确认数量，说明两个人对这次购买达成了一致。这里没有出现新的目的地，也没有说往返票。不要因为脑中熟悉的旅行流程，就把原句没有提到的票种和路线补进去。

今天只抓一个数量表达：用张来数车票。日语里数票和纸这样薄而平的东西，有常用的量词。先听一句向工作人员提出的请求，注意两张的位置。它比朋友之间说一起买吧，更适合窗口购买的关系。

切符を二枚ください。

刚才是在说，请给我两张车票。今天练的是请求，所以把原片里的共同提议换成了请给我。购买对象仍然是车票，数量仍然是两张。角色关系改变了，句子的结尾也要跟着改变，不是把原片一句话搬到任何地方都一样自然。

数薄而平的东西时，可以先把数字和量词连在一起记。我们只练一张、两张、三张，先让常见数量能顺口说出来。这个量词不能直接套到所有物品，比如杯子和动物就不是同一种数法。今天把范围留在票上，避免同时记太多规则。

切符を一枚ください。

切符を三枚ください。

接下来只改变人数。一个人出行，请给我一张；三个人同行，请给我三张。请求的目标不变，数字随着实际人数调整。练习时可以在桌面上摆出一张、两张、三张纸，让数量和声音对应，而不是只背一段抽象的数数录音。

现在轮到你跟读。每句之后都有时间，请先听清数量，再把请求说完整。不要因为其他部分已经熟悉，就把一张和两张含糊带过。真正买票时，数量是对方必须听明白的信息，慢一点说清楚，比一口气念得很快更有用。

切符を二枚買おう。

うん、二枚だね。

切符を二枚ください。

切符を一枚ください。

切符を三枚ください。

假设你和一位朋友站在窗口前，每人需要一张票。请向工作人员说出你的请求。这一遍没有同伴替你确认，你要自己决定数量。先想清楚一共有几个人，再说要买什么、几张，最后把请求收好。
