一句请求，一句答应

伞就在眼前，两个人都看得见，所以她先点出想借的东西，再用一个简短问题，把决定留给朋友。听听整句是怎样连起来的。

朋友回应，嗯，拿去用吧。这次交流里，对方已经明确答应，围巾熊才放心。我们练的不只是借东西的词，还有问完之后，停下来听回答的习惯。

最后只说一声谢谢。朋友之间的语气比较轻松，三句都不长。先把场景和每句话的目的连在一起，不用急着在脑中换算每一个字。

核心表达：先征求同意

傘、借りてもいい？

意思是，我可以借一下伞吗？前面说明要借什么，后面询问可不可以。把它听成完整的一句请求，问完不要立刻接着解释，让朋友有时间回应。

傘、借りてもいい？

这个版本适合熟悉的朋友。和不熟悉的人交谈时，需要另外考虑更客气的说法，今天先练画面里两位朋友的自然交流。语调保持询问，不把句尾拖得很长，也不说成命令。

换成笔，再问能不能坐

要在桌边写点东西，发现自己没带笔。同样先问朋友可不可以借。

意思是，我可以借一下笔吗？想借的东西变了，请求同意的目的没变。说清楚笔，再把后面的话接完整。

再换一个动作。你想坐到朋友旁边的空位置，先问一句。
